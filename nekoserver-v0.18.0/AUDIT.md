# NekoServer v0.18.0 audit

753 Python regression tests, 12 focused policy tests (overlapping the regression suite), 32 Rust tests and 90 release checks passed. Rust formatting, Clippy with warnings denied, static production/isolated-fixture builds and archive integrity checks passed. Exact current evidence and limitations are in audit-evidence/EVIDENCE-NOTES.md.

Default policy: no scheduled NekoServer media API audit and no automatic raw music backup. Applying the retained cleanup modules disables/stops recognized old media-health/music-backup timers and services; customized administrator units are preserved and reported. Music library/download files remain on SSD and are excluded from monthly payloads and rollback too. Application accounts/playlists/settings retain their existing state-backup policy. The dashboard reports routine media checks as disabled and omits retired music backup status. Acceptance checks disabled timers as absent/inactive. Monthly update pre/post health gates and explicit ad hoc diagnostics remain.

Managed photo originals plus database preservation is one weekly Sunday 02:15 Asia/Jerusalem worker; external photo copying is weekly Sunday 03:00, ordered after an active local backup. Old frequent archive timers are retired and the old daily SQL timer is rewritten weekly. Weekly status uses a weekly overdue allowance and one combined outcome. Catch-up is disabled for these night-only timers; a missed schedule waits until the next week or a manual run. New photos may wait roughly a week for the independent copy. Immich's internal SSD-local backup feature is separate. Monthly full cold recovery snapshots/rehearsals/updates and nightly app/host-state backups remain unchanged. No user files or backup generations are deleted.

See STORAGE.md for exact schedules, coverage and upgrade behaviour. Real installation, containers, accounts, application connections/playback, host permissions/sandbox, drive identity/standby/wake, USB behaviour and independent restoration still need acceptance on the intended PC. This tested installer release does not claim the physical server is already deployed.
